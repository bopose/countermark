C2PA manifest reader

PNG, JPEG, WebP, AVIF, and HEIC image files can carry an embedded "Content Credentials" manifest (the C2PA standard) claiming things like what tool produced the image. This reads that manifest and shows exactly what it says.

What this tool can and cannot tell you — read this first

It can find an embedded C2PA manifest, decode its structure, and show you every label and claim inside it — what tool it says produced the file, what actions it claims (created, edited, …), and any other assertions the manifest makes.

It cannot verify any of it. C2PA manifests are cryptographically signed, and confirming that signature — proving the manifest is genuine and the file hasn't been tampered with — needs X.509 certificate handling and public-key cryptography. Python's standard library has none of that, and adding a crypto dependency would break the "read every line, trust nothing hidden" design this whole tool relies on. So: a tampered or entirely fabricated manifest would look identical to a genuine one here. This tool shows you what a file claims, never proof.

That's also exactly why this exists: C2PA metadata is fragile — it doesn't survive screenshots, format conversion, or re-saving. Reading it now and exporting it to a durable, independent record (below) is how that claim survives even after the original container can't carry it anymore.
